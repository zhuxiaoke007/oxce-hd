# P11 修复报告 — 中文长文本自动换行失败（百科描述溢出）(2026-08-25)

## 现象

Ufopaedia 百科词条（如「空中游侠」「拦截机」）的描述文字单行超长、
延伸到右侧属性栏区域造成重叠。中文字符由于长度关系比英文更容易超宽，
英文版配的词条换行（\n）对中文不适用。

## 根因

自动换行（`Text::setWordWrap`）的模式按语言选择（zh-CN = WRAP_LETTERS，
按字符断行 ✓）。但 wrap 触发有条件守卫：

```cpp
if (_wrap && width >= getWidth() && ... && word < getWidth())
```

`word` 是自上一个「分隔符」以来累计的宽度；而 `Unicode::isSeparator`
只认 `-` 和 `/`——**中文句子的全角标点（，。；：、等）不是分隔符**，
于是整句被当作一个超宽 word；当整句宽 >= 列宽时 `word < getWidth()`
恒为假 → wrap 永不触发 → 单行溢出。

## 修复（两处）

| 文件 | 改动 |
|------|------|
| `Interface/Text.cpp` | WRAP_LETTERS 模式下放宽守卫：只要**当前行宽 > 单字宽**（排除「单字超宽」导致的无限循环情形）即允许按字符折行——中文无空格句子现在每字符可断 |
| `Engine/Unicode.h` | `isSeparator` 增加 CJK 全角标点（、。，；：！？（）《》「」）：标点处重置 word 测量，且后续按 word 回溯的逻辑也恢复到列宽内（双保险），折行更自然 |

## 验证（自动化，-hdshot:ufop.sav 场景直达百科页）

| 检验 | 修复前 | 修复后 |
|------|--------|--------|
| 描述行数 | 单行超长 | **两行**（视觉模型确认） |
| 与右侧属性栏重叠 | 重叠 | **无重叠** |
| 宽度 | 溢出可视区 | 合理宽度内 |

修复对全部 Ufopaedia 描述控件（ArticleStateCraft/Item/Text/Soldier/Armor…）
与任何使用 setWordWrap 的中文文本通用。
